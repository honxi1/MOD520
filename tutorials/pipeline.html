模型 MOD 制作流程总览

一条完整模型 MOD 的诞生，核心就四步：提取/解包 → 编辑 → 注入 → 发布。下方思维导图展示全貌，线性流程给出每一步的明细。

流程速览
  1. 提取 / 解包
  2. 编辑（模型 · 贴图）
  3. 注入
  4. 发布

思维导图

思维导图 线性分步详解
1

提取 / 解包

锁定目标引擎 → 破解/解包 → 抓取网格与贴图。

目标引擎Unity · UE · Source · RE · FromSoft（只狼/法环）
aesfinder定位加密资源（如 UE .pak）的密钥
帧转储 dump运行时转储内存/顶点数据
Ninja Ripper挂接 DirectX，抓取网格 mesh
网格 mesh 提取解包后导出模型与 UV

常用：aesfinder、Ninja Ripper、3dmigoto Loader、各引擎专用解包器

▼
2

编辑（模型 · 贴图）

整理网格与权重 → 重做贴图材质 → 可选动画。

模型处理权重重做 · 权重传递 · 骨骼权重 · 骨骼改名 · 权重改名 · 骨骼合并插件 · 改名脚本 · 无绑骨
3D 软件Blender（泛用）· 3ds Max（专业）· ZBrush（雕刻高模）· 布料模拟/服装 UV
贴图与材质基础色 · 金属度 · 粗糙度 · 环境光遮蔽 · 发光颜色 · 发光度 · 透明度/遮罩 · 法线贴图 · 凹凸 · 普通材质 · SSS 贴 · MOD 加密
贴图软件Photoshop · paint.net
动作骨骼动画 · 逐帧动画

3D 软件：Blender（泛用性好）、3ds Max（专业性强）、ZBrush（雕刻高模）；贴图用 Photoshop / paint.net

▼
3

注入

把成品装回游戏，验证替换生效。

Mod Engine以挂载方式加载，无需改原文件
3dmigoto Loader运行时替换模型/贴图
备份原文件出错可一键还原
▼
4

发布

选好平台，附上预览图与安装说明。

N 网Nexus Mods，全球主流平台
香蕉网国内游戏 MOD 社区
爱发电收费/赞助分发
视频网站演示预览 + 引导下载
踩蘑菇等社区论坛发帖交流
核心流程：提取/解包 → 编辑 → 注入 → 发布。解包用 aesfinder / Ninja Ripper，模型处理在 Blender / 3ds Max，贴图在 Photoshop / paint.net，最终用 Mod Engine / 3dmigoto Loader 注入。
