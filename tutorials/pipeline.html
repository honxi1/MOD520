模型 MOD 制作流程总览

一条完整模型 MOD 的诞生，大致走「选游戏 → 逆向解包 → 模型与绑骨 → 贴图材质 → 动画 → 挂载 → 发布」七步。以下总览按实际制作顺序展开，点开对应章节可看详细步骤。

流程速览
  1. 目标游戏与引擎
  2. 逆向解包 · 提取模型
  3. 模型与绑骨
  4. 贴图与材质
  5. 动画（可选）
  6. 挂载与加载
  7. 发布与分享
1

目标游戏与引擎

先确认游戏的技术栈，决定用什么工具解包。

Unity资源常见于 .assets / AssetBundle
UE 虚幻引擎.pak 打包，需先解密再解包
Source 起源引擎.vpk 资源包
RE 引擎卡普空游戏专用格式
FromSoft只狼 · 艾尔登法环 等
其他单机游戏按具体引擎选择工具链
▼
2

逆向解包 · 提取模型

拿到加密资源 → 解包 → 抓取网格（mesh）。

aesfinder定位游戏文件的 AES 加密密钥
帧转储 dump在运行时转储内存/顶点数据
Ninja Ripper挂接 DirectX，抓取网格 mesh
网格 mesh 提取解包后导出模型与 UV

常见工具：aesfinder、Ninja Ripper、3dmigoto Loader 及各引擎专用解包器

▼
3

模型与绑骨

整理网格 → 处理骨骼权重 → 必要时重新绑骨。

网格处理清理、合并、修复法线
绑骨 / 骨骼权重模型跟随骨骼正确变形
权重重做修正不合理的权重分布
权重传递从一个模型复制到另一个
骨骼改名对齐不同骨架的命名
权重改名权重组与骨骼名保持一致
骨骼合并插件合并多个骨架为一套
改名脚本批量处理骨骼/权重命名
无绑骨方案静态模型或直接替换，跳过绑骨

3D 软件：Blender（泛用性好）、3ds Max（专业性强）、ZBrush（雕刻高模）；可选 布料模拟 · 服装设计 · UV

▼
4

贴图与材质

制作 PBR 贴图通道，挂接材质，必要时加密。

基础色Base Color
金属度Metallic
粗糙度Roughness
环境光遮蔽Ambient Occlusion
发光颜色Emissive Color
发光度Emissive Intensity
透明度 / 透明遮罩Alpha / Alpha Mask
法线贴图Normal Map
凹凸Bump
普通材质基础着色
SSS 贴图次表面散射，皮肤/布料用
MOD 加密保护贴图资源不被直接提取

贴图软件：Blender、Photoshop、paint.net

▼
5

动画（可选）

模型带动作需求时才进入此步。

骨骼动画骨骼驱动的关键帧动画
逐帧动画序列帧播放，适合特效/纸片
动作导入复用或移植游戏内动作
▼
6

挂载与加载

把成品装回游戏，验证替换是否生效。

Mod Engine以挂载方式加载，无需改原文件
3dmigoto Loader运行时替换模型/贴图
备份原文件出错可一键还原
▼
7

发布与分享

选好平台，附上预览图与安装说明。

N 网Nexus Mods，全球主流平台
香蕉网国内游戏 MOD 社区
爱发电收费/赞助分发
视频网站演示预览 + 引导下载
踩蘑菇等社区论坛发帖交流
工具选型参考：解包用 aesfinder / Ninja Ripper / 引擎专用解包器，模型处理在 Blender / 3ds Max，贴图在 Photoshop / paint.net，最终用 Mod Engine / 3dmigoto Loader 挂载。
