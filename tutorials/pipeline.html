MOD 制作大框架

MOD 制作不只是写代码，它是一条完整链路：制作 → 维护 → 发布/变现。本站主要覆盖三系：魂系（法环 / 只狼 / 黑魂，FromSoft 自家引擎）、米哈游系（原神 / 崩坏）、UE 引擎游戏（铁拳8 / FF7 重制 / 剑星 等）。同一套流程，各游戏工具链不同，下文对号入座。

三系游戏工具链总览

解包 WitchyBND · 挂载 Mod Engine 2 / PAK+SigBypasser

制作

核心三步：提取 → 修改 → 挂载，各游戏对照如下。

环节 魂系（法环/只狼/黑魂） 米哈游系（原神/崩坏） UE 引擎（铁拳8/FF7 重制）
提取 / 解包 WitchyBND + SoulsFormats 解 .bnd/.dcx，导出 .flver 模型与 .tpf 贴图 3dmigoto 帧转储 dump，运行时抓模型与贴图 FModel 解 .pak；aesfinder / 密钥表定位 AES Key
修改 · 模型 FLVER 导入 Blender / 3ds Max，处理网格、骨骼权重、UV、法向 3dmigoto 导出网格 → Blender 处理 → 重新导入 UModel/UEViewer 导出 .glb/.fbx → Blender 处理
修改 · 材质贴图 .tpf/.dds 贴图，.mtb 材质参数，PS 编辑 .ini 缓冲配置 + .dds/.png 贴图替换 Texture2D 导出 png → PS 编辑 → 重新打包
挂载 Mod Engine 2 挂载；法环另可用 PAK + SigBypasser 3dmigoto Loader（GIMI）注入，免改原文件 repak/UnrealPak 打包 .pak → 游戏根目录 ~mods
通用心法：提取是把素材拿到手，修改是加工素材，挂载是让游戏读到你改完的东西——三系游戏都能套进这个流程，差别只在工具。
